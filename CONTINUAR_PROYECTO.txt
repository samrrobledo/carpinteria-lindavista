CÓMO PUBLICAR — PASOS PENDIENTES
──────────────────────────────────

PASO 1: Crear cuenta GitHub (si no tienen)
- Ir a github.com → Sign up
- Elegir username (ej: carpinteria-lindavista)

PASO 2: Crear repositorio
- Click en "New repository"
- Nombre: carpinteria-lindavista
- Visibilidad: Public
- Click "Create repository"

PASO 3: Subir archivos
- En el repositorio, click "uploading an existing file"
- Subir estos archivos:
    1. index.html  (el sitio web completo)
    2. CNAME       (archivo de texto sin extensión, contiene solo: carpinterialindavista.com.mx)
    3. assets/     (carpeta con las fotos work-01.jpg a work-13.jpg)

PASO 4: Activar GitHub Pages
- Settings → Pages → Source: Deploy from branch → main / (root) → Save
- URL temporal: https://TU-USUARIO.github.io/carpinteria-lindavista

PASO 5: Conectar dominio en Hostgator
- Entrar a Hostgator → My Account → Domains → carpinterialindavista.com.mx → DNS Management
- Agregar 4 registros tipo A:
    @ → 185.199.108.153
    @ → 185.199.109.153
    @ → 185.199.110.153
    @ → 185.199.111.153
- Agregar 1 registro CNAME:
    www → TU-USUARIO.github.io

PASO 6: Configurar dominio en GitHub
- En el repositorio → Settings → Pages → Custom domain
- Escribir: carpinterialindavista.com.mx → Save
- Activar "Enforce HTTPS" (aparece después de unos minutos)

NOTA: Los DNS tardan entre 30 min y 24 horas en propagarse.

APPS SCRIPT (pegar en Google Apps Script):
───────────────────────────────────────────
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(['Fecha', 'Nombre', 'Teléfono', 'Tipo de mueble', 'Medidas', 'Presupuesto', 'Cuándo', 'Detalles']);
      sheet.getRange(1, 1, 1, 8).setFontWeight('bold');
    }
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.fecha || new Date().toLocaleString('es-MX'),
      data.nombre    || '',
      data.telefono  || '',
      data.tipo      || '',
      data.medidas   || '',
      data.presupuesto || '',
      data.plazo     || '',
      data.detalles  || ''
    ]);
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'ok' }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'error', message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
